First release of Nvidium for **GT New Horizons 2.9 / Angelica 2.2.19**. Alpha quality: back up your instance first.

**Download `nvidium-0.2.0.jar`** below and put it in your `mods` folder. Requires an NVIDIA GTX 16xx / RTX 20xx or newer GPU.

### Changes since ohentis' 0.1.0-alpha5
- Ported to Angelica 2.2.19 (Celeritas 2.5.11); uses Celeritas' own asynchronous occlusion search.
- Render distance slider raised to 256 chunks (`max_render_distance`), including Celeritas' occlusion lattice limit.
- Mesh cache: terrain is saved to `.minecraft/nvidium-cache/` and shown almost instantly after rejoining a server.
- Out of VRAM: the farthest terrain is dropped first instead of punching holes near the player.
- Textured Distant Horizons LODs with shader packs (when Distant Horizons is installed).
- Fixed: Angelica's shader compatibility layer breaking Nvidium's mesh shader programs (crash and runaway memory use).
- Fixed: invisible entities, dropped items and particles.
- Fixed: distant terrain flickering from depth-precision in the occlusion culling.
- Fixed: one broken block renderer (e.g. Forestry logs in cached chunks) crashing the whole chunk renderer.
- Fixed: dedicated servers crashing when the mod is installed.

See the [README](https://github.com/zur1801/nvidium-gtnh#readme) for recommended companions (Bobbert, Distant Horizons) and render distance advice.
